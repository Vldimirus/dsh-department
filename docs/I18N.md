# Мультиязычность (i18n)

## Принципы

- **Один словарь на язык**, ключи в `dot.case`; нет строк в разметке.
- **Fallback** — русский: отсутствующий ключ не ломает интерфейс.
- **Интерполяция** — `{name}`; плюрализация — отдельная функция для ru/en (следующий этап).
- Язык выбирается: `localStorage['dept-lang']` → `navigator.language` → `ru`.
- Переключатель — кнопка `EN`/`RU` в шапке доски.

## Что уже переведено

- навигация доски: Доска/Проекты/Офис/Схема/Графики/Обновить;
- офис: заголовок, счётчик сотрудников, «отдел на паузе»;
- карточка задачи: вкладки (Обзор, Документы, Вопросы, Аудит, События, Корректировки, Роли, Бюджет, Git), Пауза/Продолжить;
- проекты.

## Что переводится следующим этапом

1. **Серверные тексты** (аудит, события, рекомендации `dept_health`) — сейчас формируются
   в `src/tools.js`/`verify.js` на русском. План: locale в состоянии задачи (`state.locale`)
   или заголовок `Accept-Language`; форматтеры получают `t`.
2. **Описания инструментов** — оставить английскими (модель читает их лучше), а
   пользовательские `summary`/`render` локализовать.
3. **Документы** — `README.md` (ru) + `README.en.md` (en); шаблоны (`templates/release.md`) — по языку задачи.
4. **Письма/служебные записки** — генерируются руководителем; язык задаётся в промпте.

## Как добавить ключ

1. Добавить ключ в `LOCALES.ru` и `LOCALES.en` в `client.js`.
2. Использовать `t('key')` / `t('key', { n })`.
3. Проверить обе локали в превью (`localStorage['dept-lang']`).

## Технический долг

- Словарь живёт в `client.js`; при росте >300 ключей вынести в `locales/*.json`
  и собирать в бандл скриптом (`tools/build-locales.mjs`).
- Пока нет плюрализации: «1 сотрудник / 2 сотрудника» — сделать `plural(lang, n, forms)`.
