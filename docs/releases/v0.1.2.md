## dsh-department 0.1.2

Двуязычный интерфейс и первые публичные релизы.

### Что нового

- **Локализация ru/en**: переключатель **EN/RU** в шапке доски, выбор запоминается;
  переведены доска, карточка задачи, вкладки, стадии, события, аудит, документы,
  корректировки, роли, бюджет, Git, офис, схема проекта, графики, формы.
- **Исправлены русские ключи**: имя панели в сайдбаре снова «ИИ-отдел»;
  проверка паритета словарей — 226 ключей в каждом языке.
- **Релиз как штатная фаза**: `dept_start release=true` подставляет шаблон
  `templates/release.md` (пакет, документация, QA-чек-лист, changelog, тег).
- **GitHub Actions CI**: тесты на каждый push/PR.
- **README**: полная английская версия (`README.md`), русская — `README.ru.md`,
  скриншоты панели, офиса, паузы и персонажей.
- Чистка репозитория от временных спрайт-инструментов.

### Установка

Требования: DeepSeek Harness >= 0.2.0, Node >= 24.9.

```bash
dsh plugin --profile web add dsh-department@0.1.2
```

Перезапустить DSH, открыть панель «ИИ-отдел».
