## dsh-department 0.2.1

Удобный запуск отдела.

### Что нового

- **Создание задачи без ручной подготовки**: git инициализируется сам, ID и название
  подставляются из папки, `npm test` определяется по `package.json`.
- **Выбор папки** через обзор каталогов и список известных проектов.
- **Автостарт**: при создании задачи плагин открывает чат руководителя и отправляет
  готовый промт (обсуждение → ТЗ → концепция).
- **«Запустить отдел»** для уже существующей задачи.
- **«Удалить»** задачу — папка уезжает в `docs/department/.trash`.

### Установка

```bash
dsh plugin --profile web add dsh-department@0.2.1
```
