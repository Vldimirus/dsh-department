## dsh-department 0.2.0

Обсуждение, жёсткие гейты и подготовка к продакшену.

### Что нового

- **Обсуждение задачи** (`discussion.md`) — цели, не-цели, пользователи, ограничения, риски,
  вопросы и решения. ТЗ нельзя утвердить, пока есть открытые вопросы.
- **ТЗ и концепция в любом порядке**: можно начать с любого документа; после утверждения
  первого отдел переходит ко второму. Запуск — только когда утверждены оба.
- **Концепция без двух вариантов не утверждается** (варианты с плюсами/минусами и выбором).
- **Из ревью нельзя проскочить**: переходы `spec_review ↔ concept` и `concept_review ↔ spec`
  только через утверждение человеком.
- **Стадия `release`**: `dept_handover` собирает `delivery/` — RUN.md (как запустить),
  MANUAL-QA.md, CHANGELOG.md, RELEASE.md и копии ТЗ/концепции/плана. Без пакета `done` недоступен.
- **Встроенный пиксель-редактор** в панели: трафарет, сохранение в проект, передача художнику.
- **«Отдел вкл/выкл»** и **«＋ Задача»** в шапке панели.

### Установка

```bash
dsh plugin --profile web add dsh-department@0.2.0
```
