## dsh-department 0.2.2

Отдел не засыпает после утверждений.

### Что нового

- После «Утвердить ТЗ» руководитель получает промт «сделай концепцию».
- После «Утвердить концепцию» — «составь план и начинай этап 1».
- Кнопка «Запустить отдел» теперь отправляет промт **по текущей стадии**, а не всегда
  «начни обсуждение».

### Установка

```bash
dsh plugin --profile web add dsh-department@0.2.2
```
