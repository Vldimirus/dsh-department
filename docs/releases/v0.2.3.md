## dsh-department 0.2.3

Отдел больше не засыпает после этапа.

### Что нового

- `dept_health` исключает самого руководителя из счётчика активных: раньше он всегда
  видел «working 1» и останавливался.
- Сторож быстрее подхватывает простой: 5 минут вместо 15, кулдаун 10 минут.

### Установка

```bash
dsh plugin --profile web add dsh-department@0.2.3
```
