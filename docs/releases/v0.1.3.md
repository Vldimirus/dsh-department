## dsh-department 0.1.3

Публикация через Trusted Publishing и полная английская документация.

### Что нового

- **Английский README** — главная страница GitHub и npm; русская версия в `README.ru.md`,
  переключатель языка в обоих файлах.
- **Скриншоты** панели, офиса, паузы и персонажей.
- **GitHub Actions**:
  - CI на каждый push/PR;
  - по тегу `v*` — авто-создание релиза и публикация в npm через Trusted Publishing
    (`npm publish --provenance`), без токенов.
- Убраны временные инструменты подготовки спрайтов.

### Установка

```bash
dsh plugin --profile web add dsh-department@0.1.3
```

Требования: DeepSeek Harness >= 0.2.0, Node >= 24.9.
