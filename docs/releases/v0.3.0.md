## dsh-department 0.3.0

Дизайн стал обязательным этапом.

### Что нового

- Стадии **design → design_review**: проект не запускается, пока человек не утвердил дизайн.
- **Гейт дизайна**: 3+ референса со ссылками, макет/палитра/типографика и минимум один
  скриншот или эскиз в `references/`.
- **`dept_reference`** — дизайнер снимает скриншот страницы или скачивает картинку.
- **`dept_design`** — читает design.md, референсы и отметки человека.
- Вкладка **«Дизайн»** в карточке: галерея и отметки «♥ Нравится» / «✗ Не то» с комментариями.

### Установка

```bash
dsh plugin --profile web add dsh-department@0.3.0
```
